# Guardião Financeiro · Dynamic Programming
Recomendador de renegociação de dívidas (mochila 0/1) para idosos atendidos no posto do Guardião Financeiro.
1. Instale as dependências: `pip install notebook matplotlib`
2. Abra o notebook: `jupyter notebook guardiao_renegociacao.ipynb` (ou faça upload no Google Colab)
3. Rode tudo em *Run > Run All Cells*: o cenário, os testes e a medição de eficiência são executados em sequência.
